Conditions d'utilisation

Dernière mise à jour : 16 août 2026

Personal Video Uploader est un projet privé d'application de bureau en cours de développement, destiné uniquement à l'usage personnel de son propriétaire.

Objet

Le projet a pour objectif de permettre au propriétaire de publier sur sa propre chaîne des fichiers vidéo de montage de danse préparés localement, notamment sous plusieurs versions linguistiques.

Statut actuel

La fonctionnalité d'importation automatique utilisant les services API YouTube est encore en cours de développement et n'est pas actuellement disponible pour une utilisation en production.

Services API YouTube

Lorsque les fonctionnalités utilisant les services API YouTube seront mises en service, leur utilisation sera soumise aux Conditions d'utilisation de YouTube .

En utilisant les fonctionnalités du client API reposant sur les services API YouTube, l'utilisateur accepte d'être lié par les Conditions d'utilisation de YouTube.

Usage privé

L'application n'est pas proposée comme service public ou commercial et n'est pas distribuée à des utilisateurs tiers.

Confidentialité

Les règles applicables au traitement prévu des données et aux autorisations OAuth sont décrites dans la Politique de confidentialité.
