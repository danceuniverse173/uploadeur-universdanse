Politique de confidentialité

Dernière mise à jour : 16 août 2026

Personal Video Uploader est un projet privé d'application de bureau destiné uniquement à l'usage de son propriétaire. Le projet prévoit d'utiliser les services API YouTube ainsi qu'OAuth 2.0 pour l'importation autorisée de vidéos sur la chaîne du propriétaire.

Statut actuel :

La fonctionnalité d'importation via les services API YouTube est encore en développement. Elle n'est pas actuellement disponible pour une utilisation en production.

Services API YouTube

Lorsque l'intégration sera activée, Personal Video Uploader utilisera les services API YouTube. Ces services seront utilisés uniquement pour les fonctions autorisées par le propriétaire, notamment l'importation de ses propres vidéos et la définition des métadonnées associées.

Informations auxquelles l'application prévoit d'accéder

L'application demandera uniquement les autorisations nécessaires à la fonction d'importation. Elle pourra traiter les informations nécessaires pour identifier la chaîne autorisée et effectuer les opérations d'importation demandées par le propriétaire.

L'application ne demande pas le mot de passe Google du propriétaire et ne stocke pas ce mot de passe. L'autorisation sera gérée par OAuth 2.0.

Utilisation des données

Les données obtenues par les services API YouTube seront utilisées uniquement afin d'exécuter les actions demandées par le propriétaire de l'application. Elles ne seront ni vendues, ni utilisées pour du profilage publicitaire, ni partagées avec des tiers à des fins marketing.

Stockage des données d'autorisation

Une fois OAuth activé, des jetons d'autorisation pourront être enregistrés localement sur l'ordinateur du propriétaire afin de permettre les requêtes autorisées. Ces données resteront sous le contrôle du propriétaire de l'application.

Suppression et révocation

Le propriétaire pourra supprimer les données d'autorisation stockées localement en supprimant les fichiers de jetons de l'application. Il pourra également révoquer l'accès accordé à l'application depuis les paramètres de sécurité de son compte Google.

Après suppression ou révocation, l'application ne pourra plus utiliser les autorisations concernées tant qu'une nouvelle autorisation OAuth n'aura pas été accordée.

Contrôle par l'utilisateur

Le propriétaire conserve le contrôle de l'accès accordé à l'application et peut interrompre cette autorisation à tout moment. Comme l'application est privée et destinée uniquement à son propriétaire, aucune donnée d'utilisateur tiers n'est prévue dans le fonctionnement du projet.

Google et YouTube

L'utilisation future des services API YouTube sera soumise aux Conditions d'utilisation de YouTube .

Le traitement des informations par Google est décrit dans la Politique de confidentialité de Google .

Mises à jour de cette politique

Cette politique sera mise à jour si le fonctionnement du projet ou le traitement des données évolue. Les informations publiées sur cette page doivent refléter le fonctionnement réel de l'application au moment de sa mise en service.
